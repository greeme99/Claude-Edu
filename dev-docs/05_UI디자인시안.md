## 1. 디자인 방향

### 1.1 제품 성격 판정

이 서비스는 **SaaS 랜딩이 아니라 장문 한국어 문서 플랫폼**이다. 이 판정이 모든 결정을 좌우한다.

| 판정 | 결과 |
|---|---|
| 제품 유형 | 교육 콘텐츠 · 문서형 (Documentation / Long-form reading) |
| 주 사용자 | 30~50대 비개발 실무자 (제조·품질·SCM·마케팅) |
| 주 행위 | **10~15분 길이의 한국어 본문 읽기** |
| 스타일 | 편집·교재 기반 미니멀리즘 + 층위(Stratum) 시그니처 |
| 히어로 | 없음. 화면 높이만 한 히어로를 두지 않는다 |

### 1.2 시그니처 — 층위(Stratum)

커리큘럼 자체가 **프롬프트 → 컨텍스트 엔지니어링 → 하네스 → MCP → Skills**의 5개 계층 구조다. 이 구조를 시각 언어로 가져왔다.

| 적용 위치 | 형태 |
|---|---|
| h2 규칙선 | 본문 폭 전체 하어라인 + 좌측 끝 34px 쪽빛 마디 |
| 로고 | 길이가 줄어드는 막대 3개를 쌓음 |
| 차시 번호 | 막대 2개 + 트랙·차시 표기 |
| 그룹 헤딩 | h2 규칙선과 동일 구조 |

장식이 아니라 **이 교재가 가르치는 구조를 그대로 쓴 것**이다. 다른 주제였다면 성립하지 않는다.

### 2.2 적용 규칙

| ID | 규칙 |
|---|---|
| CL-01 | **강조색은 쪽빛(indigo) 하나뿐이다.** 자황(ochre)은 상태 표시 전용이므로 강조색으로 세지 않는다 |
| CL-02 | 자황은 **신규 배지 · 자리표시자 `[대괄호]` · 링크 확인 필요 표식**에만 쓴다. 다른 용도로 확장 금지 |
| CL-03 | **색만으로 의미를 전달하지 않는다.** 항상 라벨·아이콘·형태를 동반한다 (NFR-05 · ui-ux-pro-max 우선순위 1) |
| CL-04 | 중성색에 **온기를 넣었다.** 순회색은 장시간 독서에서 임상적으로 느껴진다. 다만 크림(#F4F1EA)까지 가지 않고 중성 온회색에서 멈춘다 |
| CL-05 | 컴포넌트에 **생 hex를 쓰지 않는다.** 반드시 토큰 경유 (ui-ux-pro-max 우선순위 6) |
| CL-06 | 다크 테마는 **토큰만 재정의**한다. 미디어 쿼리나 `[data-theme]` 블록 안에서 컴포넌트를 스타일링하지 않는다 |

### 2.3 테마 판정 구조

뷰어의 테마 상태는 3가지다. 아래 순서로 정의해야 세 상태가 모두 성립한다.

```css
:root{ /* 라이트 전체 팔레트 — 기준 */ }
@media (prefers-color-scheme:dark){
  :root:not([data-theme="light"]){ /* 토큰만 재정의 */ }
}
:root[data-theme="dark"]{ /* 토큰만 재정의 */ }
```

`body`에는 반드시 토큰 배경을 명시한다. 투명 배경은 호스트 바탕을 빌려와 테마가 깨진다.

### 2.4 대비 검증

| 조합 | 라이트 | 다크 | 기준 |
|---|---|---|---|
| `--ink` on `--paper` | 15.8:1 | 14.2:1 | AAA |
| `--ink-2` on `--paper` | 9.6:1 | 9.1:1 | AAA |
| `--muted` on `--paper` | 5.2:1 | 5.4:1 | AA ✅ |
| `--indigo` on `--surface` | 9.1:1 | 7.3:1 | AAA |
| `--ochre` on `--ochre-soft` | 5.9:1 | 6.2:1 | AA ✅ |

> 수치는 설계 목표값이다. 구현 후 자동 검사로 재확인한다 (AC-07).

## 3. 타이포그래피

### 3.1 서체 조합

```html
<link rel="stylesheet" href="https://fonts.googleapis.com/css2?family=Gowun+Batang:wght@400;700&family=IBM+Plex+Sans+KR:wght@300;400;500;600;700&family=IBM+Plex+Mono:wght@400;500;600&display=swap">
```

| 역할 | 서체 | 근거 |
|---|---|---|
| Display · Heading | **Gowun Batang** (고운바탕) | 한국어 바탕 계열. 교재의 무게와 신뢰감을 만든다. 400/700만 존재하므로 제목 전용 |
| Body · UI | **IBM Plex Sans KR** | 화면 최적화 한국어 고딕. 300~700 전 굵기 보유. 모바일 판독 우선 |
| Mono · 라벨 · 코드 | **IBM Plex Mono** | Plex 패밀리로 본문과 조화. 차시 번호·ID·프롬프트 본문 |

**Inter, Pretendard, Space Grotesk를 쓰지 않았다.** 기본값 선택으로 읽히고, 한국어 교재라는 성격을 드러내지 못한다.

### 3.2 타입 스케일

| 역할 | 서체 | 크기 | 행간 | 자간 |
|---|---|---|---|---|
| 차시 제목 (h1) | Gowun Batang 700 | 37 / 27(모바일) | 1.24 | -.024em |
| 페이지 제목 | Gowun Batang 700 | 34 / 26 | 1.25 | -.02em |
| 섹션 제목 (h2) | Gowun Batang 700 | 20 | 1.4 | -.012em |
| 카드 제목 | Gowun Batang 700 | 16.5 | 1.38 | -.012em |
| **본문** | Plex Sans KR 400 | **15.5 / 15** | **1.85** | 0 |
| 부가 설명 | Plex Sans KR 400 | 13~14 | 1.62~1.72 | 0 |
| 라벨 · 메타 | Plex Mono 600 | 10.5~11.5 | 1.7 | .11~.14em |
| 코드 · 프롬프트 | Plex Mono 400 | 12.5 | 1.85 | 0 |

### 3.3 적용 규칙

| ID | 규칙 |
|---|---|
| TY-01 | **본문 행간은 1.85다.** 한국어는 받침 때문에 글자 높이가 일정하지 않아 라틴 기준값 1.5로는 답답하다 |
| TY-02 | 본문 한 줄은 **64자(ch) 이내**로 제한한다 |
| TY-03 | 제목에 `text-wrap: balance`를 적용한다 |
| TY-04 | 대문자 라벨에는 자간을 준다 (.11em 이상) |
| TY-05 | 본문 최소 크기는 15px. 12px 미만 본문 금지 |
| TY-06 | 숫자가 열로 정렬되는 표에는 `font-variant-numeric: tabular-nums` |

## 4. 간격 · 반경 · 그림자

```css
--sp:8px;                     /* 기본 단위. 모든 간격은 8의 배수 */
--r-s:4px;   /* 칩 내부·작은 버튼 */
--r-m:6px;   /* 카드·입력·버튼 */
--r-l:10px;  /* 오버레이·프레임 */
--shadow-s:0 1px 2px rgba(28,27,25,.05);
--shadow-m:0 2px 4px rgba(28,27,25,.05), 0 12px 28px -18px rgba(28,27,25,.30);
--shadow-l:0 24px 60px -22px rgba(28,27,25,.42);
```

| ID | 규칙 |
|---|---|
| SP-01 | 형제 요소 배치는 **flex/grid + gap**으로 한다. 개별 margin으로 간격을 만들지 않는다 |
| SP-02 | 반경·그림자·테두리·채움은 **역할별로** 쓴다. 모든 블록에 같은 반경과 그림자를 찍지 않는다 |
| SP-03 | 그림자는 **떠올라야 하는 것에만** 쓴다. 오버레이·팝오버·호버 카드에 한정 |

## 5. 컴포넌트 스타일

### 5.1 버튼

| 종류 | 스타일 | 용도 |
|---|---|---|
| 주 버튼 | 쪽빛 배경 + 흰 글자, `--r-m` | 화면당 최대 1개 |
| 보조 버튼 | 테두리 + `--ink-2`, 호버 시 쪽빛 | 필터 초기화, 부가 동작 |
| 텍스트 버튼 | 쪽빛 글자 + 화살표 | 인라인 이동 |
| 아이콘 버튼 | 32×32 테두리 상자 | **반드시 `aria-label`** |

### 5.2 용어 마킹 · 팝오버

```css
.term{ border-bottom:1.5px dotted var(--indigo); font-weight:500; }
.term:hover{ background:var(--indigo-soft); }
```

| ID | 규칙 |
|---|---|
| TM-01 | 쪽빛 **점선 밑줄**. 색만으로 구분하지 않도록 형태를 동반한다 |
| TM-02 | 차시당 동일 용어는 **첫 등장 1회만** 마킹 (R-05-2) |
| TM-03 | 호버 150ms 지연 후 열림. **키보드 포커스·터치로도** 열려야 한다 (NFR-06) |
| TM-04 | 화면 밖으로 나가면 위치를 자동 반전 |
| TM-05 | 동시에 1개만 표시 |

### 5.3 카드

| 상태 | 스타일 |
|---|---|
| 기본 | `--surface` + `--line` 테두리 |
| 호버 | 테두리 쪽빛 + `--shadow-m` + `translateY(-1px)` |
| 현재 | 테두리 쪽빛 유지 |

카드 전체가 클릭 영역. **대응 차시 배지는 카드 링크 밖에 배치**한다 (중첩 링크 금지 · C-04).

### 5.4 콜아웃

| 유형 | 스타일 | 용도 |
|---|---|---|
| `goal` | 좌측 3px 쪽빛 바 + 흰 면 | 학습 목표 |
| `q` | `--indigo-soft` 면, 테두리 없음, 바탕체 본문 | 핵심 질문 |
| `key` | `--surface-2` 면 + 테두리 | 핵심 정리 |
| `warn` | 좌측 3px 자황 바 | 주의·안티패턴 |

각 유형은 **라벨 텍스트를 반드시 포함**한다 (CL-03).

## 8. 사전 배포 체크리스트

ui-ux-pro-max 체크리스트에 이 프로젝트 항목을 더했다.

- [ ] 이모지를 아이콘으로 쓰지 않았다
- [ ] 클릭 가능한 모든 요소에 `cursor: pointer`
- [ ] 호버 전환 150~300ms
- [ ] 본문 대비 4.5:1 이상 — **라이트·다크 양쪽**
- [ ] 포커스 링이 보이며, 제거하지 않았다
- [ ] `prefers-reduced-motion` 존중
- [ ] 375 / 768 / 1024 / 1440px에서 검증
- [ ] 터치 목표 44×44px, 간격 8px 이상
- [ ] 가로 스크롤 없음 (표·코드는 자체 컨테이너에서만)
- [ ] 컴포넌트에 생 hex 없음 — 전부 토큰 경유
- [ ] 다크 팔레트가 미디어 쿼리 안에서만 정의된 색이 없음
- [ ] `body`에 토큰 배경 명시
- [ ] 웹폰트 폴백 스택 지정

## 10. 구현 인계

### Tailwind 매핑

```js
// tailwind.config.js
theme:{ extend:{
  colors:{
    paper:'var(--paper)', surface:{DEFAULT:'var(--surface)',2:'var(--surface-2)',3:'var(--surface-3)'},
    ink:{DEFAULT:'var(--ink)',2:'var(--ink-2)'}, muted:'var(--muted)', faint:'var(--faint)',
    line:{DEFAULT:'var(--line)',2:'var(--line-2)'},
    indigo:{DEFAULT:'var(--indigo)',2:'var(--indigo-2)',soft:'var(--indigo-soft)'},
    ochre:{DEFAULT:'var(--ochre)',soft:'var(--ochre-soft)'}
  },
  fontFamily:{ display:['"Gowun Batang"','"Nanum Myeongjo"','Georgia','serif'],
    sans:['"IBM Plex Sans KR"','-apple-system','"Malgun Gothic"','sans-serif'],
    mono:['"IBM Plex Mono"','ui-monospace','Menlo','monospace'] },
  lineHeight:{ ko:'1.85' }
}}
```

토큰은 `globals.css`의 `:root`에 CSS 변수로 두고, Tailwind는 그 변수를 참조만 한다. 테마 전환 시 Tailwind 클래스를 바꾸지 않고 변수만 교체된다.

### 인계 순서
1. `globals.css` 토큰 + 3-상태 테마 블록
2. 서체 로드 (`next/font` 또는 `<link>`)
3. 공통 컴포넌트 10종 (C-01~C-10)
4. 화면 11종 (S-01~S-11)
