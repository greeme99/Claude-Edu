## 1. 개요

### 1.1 목적
현재 PDF 3종으로 존재하는 클로드 교육 콘텐츠를, **웹에서 열람·검색·참조할 수 있고 콘텐츠 갱신이 지속 가능한 공개 웹 애플리케이션**으로 전환한다.

PDF의 한계가 이 프로젝트의 존재 이유다.

| PDF의 한계 | 웹앱이 해결하는 방식 |
|---|---|
| 용어를 찾으려면 부록 A로 이동 후 되돌아와야 함 | 본문에서 용어 툴팁으로 즉시 확인 |
| 전체 검색 불가 | 차시·용어·템플릿 통합 검색 |
| 차시 간 상호참조가 수동 (그리고 현재 7건이 깨져 있음) | ID 기반 링크로 클릭 이동, 빌드 시 검증 |
| 템플릿 25종을 복사하려면 PDF에서 긁어야 함 | 원클릭 복사 |
| 내용이 바뀌면 PDF 전체를 재배포 | 소스 수정 시 자동 재배포 |

### 1.2 제품 범위
- **포함:** 이론 7차시(기존 6 + Cowork 1), 실습 14차시(기존 12 + Cowork 2), 용어집, 프롬프트 템플릿, 추가 학습자료의 웹 열람·검색·참조
- **제외:** 4장 참조

### 1.3 용어 정의
| 용어 | 정의 |
|---|---|
| 차시 (Lesson) | 교육 콘텐츠의 최소 배포 단위. 이론 트랙과 실습 트랙으로 구분 |
| 트랙 (Track) | 차시의 계열. `theory` 또는 `practice` |
| 용어 (Term) | 부록 A 용어집의 한 항목. 본문 툴팁의 데이터 소스 |
| 템플릿 (Template) | 부록 B의 프롬프트 템플릿 한 항목 |
| 콘텐츠 소스 | 콘텐츠의 원본 저장 위치. MDX 파일 또는 Google Sheets |
| 빌드 병합 | 두 콘텐츠 소스를 빌드 시점에 정적 데이터로 합치는 과정 |
| 운영자 | 콘텐츠를 추가·수정하는 사람. 현재 그리메 1인 |

## 2. 이해관계자 및 사용자

### 2.1 이해관계자
| 구분 | 대상 | 관심사 |
|---|---|---|
| 발주 · 운영 | 그리메 (MK 컨설팅 & 코칭) | 교육 품질, 갱신 편의성, 운영 비용 |
| 주 사용자 | AX 교육 수강생 | 이해 가능성, 찾기 쉬움, 바로 써먹을 수 있음 |
| 부 사용자 | 일반 방문자 | 신뢰할 수 있는 한국어 클로드 학습 자료 |
| 잠재 | 고객사 교육 담당자 | 커리큘럼 전체 조망, 공유 가능성 |

### 2.2 사용자 유형

**U1 — 교육 수강생 (Primary)**
- 제조·품질·SCM·마케팅 등 비개발 직무 실무자 다수
- 교육 중/후에 복습하거나 특정 개념을 다시 확인하려 함
- 모바일 접근 비중이 상당함 (교육장, 이동 중)
- **핵심 니즈:** "그때 배운 그 용어가 뭐였지?"를 30초 안에 해결

**U2 — 콘텐츠 운영자 (그리메, Secondary)**
- 분기 단위 또는 주요 릴리스 시 콘텐츠 갱신
- 스프레드시트 작업에 능숙 (GAS 전문성 보유)
- **핵심 니즈:** 개발자 호출 없이 혼자 콘텐츠를 고치고 반영

**U3 — 일반 방문자 (Tertiary)**
- 검색으로 유입. 특정 개념 한 편만 읽고 이탈
- **핵심 니즈:** 단일 차시만 봐도 맥락이 이해됨

| UC-01 | 교육 중 모르는 용어가 나와 휴대폰으로 검색해 정의를 확인한다 | U1 |

## 3. 제약사항

아래는 협의로 **확정된 전제**다. 변경하려면 설계 전체를 다시 해야 한다.

| ID | 제약 | 근거 |
|---|---|---|
| C-01 | 콘텐츠는 MDX(Git)와 Google Sheets 두 소스에만 존재한다. 본문은 MDX, 표로 표현되는 레코드는 시트 | 콘텐츠 실체가 문서 21편 + 레코드 약 200행 규모로 관계형 DB가 과잉 |
| C-02 | 배포 산출물은 정적 사이트다. 런타임 DB·서버 API·시크릿이 없다 | 쿼터·과금·자격증명·보안 표면을 설계 단계에서 제거 |
| C-03 | 인증이 없다. 전면 공개 웹이다 | v1 범위 축소 결정 |
| C-04 | 시트 접근은 "웹에 게시(Publish to web) CSV"를 사용한다 | 서비스 계정 키 자체를 없애기 위함 |
| C-05 | 콘텐츠 판단은 사람이, 반영은 시스템이 한다 | 자동 생성 콘텐츠를 검증 없이 게시하지 않음 |
| C-06 | 최신화 범위는 Cowork 차시 신설로 한정한다. 기존 18편 전수 팩트체크는 v1 범위 외 | 범위 통제 |
| C-07 | 모든 사용자 대면 텍스트는 한국어다. 기술 용어·제품명·식별자는 원문 유지 | 대상 사용자 특성 |

## 4. 기능 요구사항

우선순위: **M**(Must, v1 필수) / **S**(Should, v1 권장) / **C**(Could, v2)

## 5. 비기능 요구사항

### 5.1 성능
| ID | 요구사항 | 측정 기준 |
|---|---|---|
| NFR-01 | 차시 페이지 초기 로딩이 빨라야 한다 | LCP 2.5초 이내 (모바일 4G 기준) |

## 6. 데이터 요구사항

### 6.1 콘텐츠 인벤토리

| 콘텐츠 | 소스 | v1 규모 | 증가 예상 |
|---|---|---|---|
| 이론 차시 본문 | MDX | 7편 (기존 6 + Cowork 1) | 연 1~2편 |
| 실습 차시 본문 | MDX | 14편 (기존 12 + Cowork 2) | 연 2~4편 |
| 용어 | Sheets `terms` | 70항목 (기존 60 + Cowork 10) | 연 10~20 |
| 프롬프트 템플릿 | Sheets `templates` | 25항목 | 연 5~10 |
| 추가 학습자료 | Sheets `resources` | 40항목 | 연 5~10 |
| 확인 문제 | Sheets `quiz` | 약 70항목 | 차시 추가에 비례 |
| 차시 메타 | Sheets `lessons` | 21행 | 차시 추가에 비례 |

### 6.2 데이터 무결성 요구사항
| ID | 요구사항 |
|---|---|
| DR-01 | 차시는 순번이 아닌 **불변 고유 ID**로 식별되어야 한다. 차시 삽입·재배열이 기존 참조를 깨뜨려서는 안 된다 |
| DR-02 | 용어의 `refs`는 실재하는 차시 ID만 가리켜야 한다 |
| DR-03 | 확인 문제의 `lesson_id`는 실재하는 차시 ID만 가리켜야 한다 |
| DR-04 | 차시 slug는 URL에 노출되므로 한 번 정해지면 변경하지 않는다 |

> **DR-01의 근거:** 원본 PDF에서 순번 기반 상호참조가 7건 깨져 있음이 확인되었다. 존재하지 않는 "이론 5차시 = AI 규제와 윤리"를 본문이 두 번 참조하고, 실습편은 12차시로 끝나는데 13차시를 가리킨다. Cowork 차시를 삽입하는 순간 같은 사고가 재발한다.

## 7. 범위 외 (v1 제외)

| 항목 | 제외 사유 | 재검토 시점 |
|---|---|---|
| 관리자 CMS | 인증·권한·에디터 구현으로 범위 1.5~2배 증가. 구글시트가 그 역할을 대신함 | v2 |

## 9. 가정 및 리스크

### 9.1 가정
| ID | 가정 | 틀렸을 때의 영향 |
|---|---|---|
| A-01 | 콘텐츠는 공개해도 무방하다 | 인증 도입 필요, 아키텍처 재설계 |
| A-02 | 원본 PDF 3종이 콘텐츠의 최신본이다 | 이관 대상 재확인 필요 |
| A-03 | 운영자는 1인이며 동시 편집 충돌이 없다 | 시트 잠금·승인 절차 필요 |
| A-04 | Google Sheets 무료 사용이 유지된다 | 콘텐츠를 JSON으로 이전 (경로는 확보되어 있음) |

### 9.2 주요 리스크
| ID | 리스크 | 등급 | 대응 |
|---|---|---|---|
| R-01 | 시트 열 변경으로 파싱이 조용히 깨짐 | 치명 | 헤더명 기반 조회 + 빌드 실패 처리 (FR-18) |
| R-02 | Cowork 관련 2차 자료 간 정보 충돌 | 높음 | Anthropic 1차 출처 우선, 미확인 항목은 본문에 명시 |
| R-03 | Sheets API 쿼터 초과분이 2026년 하반기부터 과금 예정 | 높음 | 런타임 호출 없음. 배포당 수 회 CSV 조회만 발생 (C-02) |
| R-04 | 구글 장애 시 빌드 실패 | 중간 | 마지막 성공 스냅샷 fallback (FR-20) |
| R-05 | 클로드 기능 변화 속도가 콘텐츠 갱신을 앞지름 | 중간 | 차시별 갱신일 노출 (FR-21) |
