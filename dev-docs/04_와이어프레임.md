| 6 | 복사 버튼 | `body`만 복사. "복사했습니다" 2초 표시 | 실패 시 자동 선택 + 안내 |
| 7 | 사용법 / 예상 결과 | 펼침 시 함께 노출 | 빈 값이면 해당 줄 생략 |
| 8 | 출처 | 고급기법(E)만 표시 | `source` 없으면 생략 |
| 9 | 앵커 진입 | 해당 카드 자동 펼침 + 스크롤 | — |

### S-08 / S-09 · 검색

**목적** 30초 안에 원하는 것을 찾는다 (UF-01).

#### S-08 검색 오버레이 (전역)

```
        ┌───────────────────────────────────────────────┐
        │ ( 🔍 컨텍스트                            ESC )│
        ├───────────────────────────────────────────────┤
        │ 용어  2건                                     │
        │  컨텍스트 엔지니어링                          │
        │  컨텍스트 윈도우                              │
        │                                               │
        │ 차시  3건                                     │
        │  이론 3차시 · 프롬프트의 한계와 컨텍스트…     │
        │   "…프롬프트를 최적화하는 행위 자체가         │
        │     **컨텍스트** 전체의 균형을…"              │
        │  실습 06 · 컨텍스트 설계 실습                 │
        │  이론 4차시 · 하네스                          │
        │                                               │
        │ 템플릿  0건                                   │
        │                                               │
        │ ─────────────────────────────────────────    │
        │ 전체 결과 보기 →                              │
        └───────────────────────────────────────────────┘
```

| # | 요소 | 동작 |
|---|---|---|
| 1 | 열기 | 헤더 🔍 클릭 또는 `/` 키 |
| 2 | 닫기 | `ESC`, 배경 클릭, 결과 선택 |
| 3 | 입력 | 디바운스 150ms. 200ms 내 결과 표시 (NFR-02) |
| 4 | 키보드 | `↑↓` 이동, `Enter` 선택 |
| 5 | 그룹 순서 | 용어 → 차시 → 템플릿 (고정) |
| 6 | 그룹당 표시 | 최대 5건 (R-03-6) |
| 7 | 차시 결과 | 매칭 문맥 발췌 + 매칭어 강조. 선택 시 해당 섹션 앵커로 이동 |
| 8 | 전체 결과 보기 | `/search?q=` 로 이동 |

**예외**
| 상황 | 처리 |
|---|---|
| 1글자 입력 | 실행 안 함. "2글자 이상 입력해주세요" |
| 결과 0건 | "'{키워드}'에 대한 결과가 없습니다" + 용어사전·커리큘럼 링크 |
| 인덱스 로드 실패 | 오버레이에 오류 안내. 다른 기능은 정상 |

#### S-09 검색 결과 페이지 `/search?q=`

오버레이와 동일한 그룹 구조에 유형 필터 탭을 추가하고, 그룹당 표시 제한을 해제한다. URL 공유가 가능하다.

## 3. 공통 컴포넌트 명세

### C-01 전역 헤더

| 구분 | 구성 |
|---|---|
| 데스크톱 | 로고 · 커리큘럼▾ · 용어사전 · 템플릿 · 자료실 · 검색 · 테마 |
| 모바일 | ☰ · 로고 · 검색 · 테마 |

- 커리큘럼▾ 은 호버/포커스로 이론·실습 하위 메뉴를 연다
- 현재 섹션에 해당하는 메뉴를 강조한다
- 모바일에서 아래로 스크롤 시 숨기고, 위로 스크롤 시 다시 나타낸다

### C-02 모바일 드로어

좌측에서 슬라이드. 커리큘럼(이론·실습 전체 차시 목록) · 용어사전 · 템플릿 · 자료실 · 소개.
차시 상세에서 열면 현재 차시를 강조하고 그 위치로 스크롤한다.
`ESC`·배경 탭·닫기 버튼으로 닫는다.

### C-03 용어 툴팁 팝오버

```
   ·컨텍스트 엔지니어링·
    ┌──────────────────────────────────┐
    │ 컨텍스트 엔지니어링                │
    │ Context Engineering               │
    │                                   │
    │ 모델에 전달되는 전체 맥락을 설계   │
    │ 하는 상위 개념                     │
    │                                   │
    │ 용어사전에서 보기 →                │
    └──────────────────────────────────┘
```

| 항목 | 동작 |
|---|---|
| 여는 조건 | 데스크톱: 호버 150ms 지연 또는 키보드 포커스 / 모바일: 탭 |
| 닫는 조건 | 포인터 이탈 300ms, `ESC`, 외부 탭, 다른 용어 열기 |
| 위치 | 기본 아래. 화면 밖으로 나가면 위로 반전 (R-05 예외) |
| 접근성 | 트리거는 `button`. `aria-describedby` 연결. 포커스 트랩 없음 |
| 동시 표시 | 항상 1개만 |

### C-04 차시 카드

| 영역 | 내용 |
|---|---|
| 상단 | 차시 번호 · (대응 차시 배지) |
| 본문 | 제목 · 요약 1~2줄 |
| 하단 | 갱신일 |

카드 전체가 클릭 영역. 대응 차시 배지만 별도 링크로 분리한다(중첩 링크 금지 — 배지는 카드 링크 밖에 배치).

### C-05 문서 내 목차

h2·h3에서 자동 생성. h4 이하는 제외.
데스크톱: 우측 sticky, 현재 섹션 강조. 모바일: 상단 접힘, 항목 선택 시 자동으로 접는다.
h2가 2개 미만이면 렌더하지 않는다.

### C-06 이전/다음 네비게이터

좌우 2칸. 각 칸에 방향 표시 · 트랙과 차시 번호 · 제목.
없는 방향은 칸을 비활성 상태로 남긴다(레이아웃 유지). 모바일은 세로로 쌓는다.

### C-07 코드블록

우상단 복사 버튼(호버·포커스 시 노출, 모바일은 항상 노출).
긴 줄은 가로 스크롤. 줄바꿈하지 않는다.
프롬프트 예시는 구문 강조 없이 등폭 서체만 사용한다(강조가 오히려 오독을 유발).

### C-08 콜아웃

| 유형 | 용도 |
|---|---|
| `key` | 핵심 정리, 학습 목표 |
| `warn` | 주의, 안티패턴 |
| `quote` | 인용, 공식 명세 |

아이콘 + 유형명 라벨을 함께 쓴다. 색만으로 유형을 구분하지 않는다(NFR-05).

### C-09 필터 바

칩 형태. 단일 선택(카테고리)과 다중 선택(난이도·언어)을 시각적으로 구분한다.
선택 상태는 URL 쿼리에 반영해 공유 가능하게 한다.
필터 결과 0건이면 "조건에 맞는 항목이 없습니다" + 필터 초기화 버튼.
모바일에서는 가로 스크롤 칩 행.

### C-10 푸터

콘텐츠 출처 · 최종 갱신 · 운영 주체 · 소개 링크. 사이트맵을 반복하지 않는다.

## 4. 인터랙션 상태 정의

모든 인터랙티브 요소가 가져야 할 상태.

| 상태 | 요건 |
|---|---|
| 기본 | — |
| 호버 | 데스크톱만. 터치 기기에서는 적용하지 않는다 |
| 포커스 | **가시적 포커스 링 필수** (NFR-04). 호버와 시각적으로 구별될 것 |
| 활성 | 눌린 상태 피드백 |
| 비활성 | 명암비를 낮추되 4.5:1 이상 유지. 커서 변경 |
| 로딩 | 검색 인덱스 로드 시에만 사용 |

**모션** `prefers-reduced-motion: reduce` 시 모든 전환을 제거한다 (NFR-07). 기본 전환 시간은 150~200ms를 넘기지 않는다.
