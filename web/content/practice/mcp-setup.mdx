## 오늘 만들 결과물

Claude가 파일시스템 <Term id="T-MCP" /> 서버를 통해 여러분 컴퓨터의 파일을 직접 검색하고 읽을 수 있게 돼요. 전에는 "이 파일 좀 읽어줘"라고 일일이 복사해 붙여야 했다면, 이제는 **"프로젝트에서 TODO가 포함된 파일을 찾아줘"** 라고 말하면 Claude가 알아서 찾아요.

<Callout type="quote">
<LessonLink id="TH-05" />에서 MCP를 배웠어요. MCP는 AI 모델이 외부 도구와 통신하기 위한 **표준 프로토콜**이에요. USB가 주변기기를 컴퓨터에 연결하는 표준이듯, MCP는 도구를 AI에 연결하는 표준이에요.

MCP의 세 가지 핵심 요소:
- **리소스(Resources)**: AI가 읽을 수 있는 데이터 (파일, DB 레코드 등)
- **도구(Tools)**: AI가 실행할 수 있는 기능 (파일 검색, API 호출 등)
- **프롬프트(Prompts)**: 미리 정의된 대화 템플릿

오늘은 이 중 **도구**를 중심으로 실습합니다.
</Callout>

## 준비물

- Claude Code (<LessonLink id="PR-07" />에서 설치 완료)
- Node.js 18 이상
- 실습용 프로젝트 폴더 (`practice-todo-app` 재활용 가능)

## 1. MCP 서버 등록

<Step n={1} title="MCP 서버를 Claude Code에 등록해요">

Claude Code의 설정 파일은 `~/.claude/settings.json`이에요. 먼저 확인해보세요.

```bash
cat ~/.claude/settings.json
```

파일이 없거나 비어 있어도 괜찮아요. 지금부터 만들 거예요.

오늘 사용할 것은 **파일시스템 MCP 서버**예요. Anthropic이 공식으로 제공하는 기본 서버 중 하나로, 지정된 폴더의 파일을 읽고·검색하고·목록 조회할 수 있게 해줘요.

```bash
claude mcp add filesystem -s user -- npx -y @modelcontextprotocol/server-filesystem ~/practice-todo-app
```

명령어를 분해해볼게요.

| 부분 | 의미 |
|---|---|
| `claude mcp add` | MCP 서버를 추가하는 명령어 |
| `filesystem` | 이 MCP 서버의 이름 (우리가 정하는 별칭) |
| `-s user` | 사용자 전역 설정에 추가 (`-s project`면 프로젝트별) |
| `--` | 뒤에 오는 것이 실제 서버 실행 명령어라는 표시 |
| `npx -y @model...` | 파일시스템 MCP 서버 패키지를 다운로드해서 실행 |
| `~/practice-todo-app` | Claude가 접근할 수 있는 폴더 경로 |

성공하면 설정 파일에 서버 정보가 추가돼요.

```json
{
  "mcpServers": {
    "filesystem": {
      "command": "npx",
      "args": [
        "-y",
        "@modelcontextprotocol/server-filesystem",
        "/home/사용자이름/practice-todo-app"
      ]
    }
  }
}
```

</Step>

### settings.json의 범위

CLAUDE.md처럼 settings.json도 두 위치에 둘 수 있어요.

| 위치 | 범위 | 플래그 |
|---|---|---|
| `~/.claude/settings.json` | 모든 프로젝트 | `-s user` |
| `프로젝트/.claude/settings.json` | 해당 프로젝트 | `-s project` |

항상 사용하는 MCP 서버는 user 범위에, 특정 프로젝트에서만 쓰는 서버는 project 범위에 등록하면 돼요.

## 2. 연결 확인

<Step n={2} title="MCP 서버가 제대로 연결되었는지 확인해요">

```bash
cd ~/practice-todo-app
claude
```

Claude Code가 시작되면서 MCP 서버에 연결을 시도해요. 시작 메시지에서 서버 목록이 표시되는지 확인하세요. 그다음 도구 목록을 물어보세요.

```
> 지금 사용할 수 있는 MCP 도구 목록을 보여줘
```

파일시스템 MCP 서버의 주요 도구는 아래와 같아요.

| 도구 | 기능 |
|---|---|
| `read_file` | 지정한 파일의 내용을 읽어요 |
| `write_file` | 파일에 내용을 써요 |
| `list_directory` | 폴더 안의 파일 목록을 조회해요 |
| `search_files` | 파일 이름이나 내용으로 검색해요 |
| `get_file_info` | 파일 크기, 수정 시간 등 메타데이터를 조회해요 |

간단한 테스트를 해보세요.

```
> 이 프로젝트의 파일 구조를 보여줘
```

Claude가 `list_directory` 도구를 사용해서 목록을 가져온 뒤 트리 구조로 정리해서 보여줄 거예요.

</Step>

<Callout type="quote">
Claude Code 자체도 파일을 읽을 수 있어요. MCP의 가치는 파일 접근 자체가 아니라, **"어떤 도구를 어떤 범위에서 사용할 수 있는지"를 명확하게 정의하는 표준**이라는 데 있어요.
</Callout>

## 3. MCP로 파일 검색·읽기

<Step n={3} title="MCP 도구를 활용해서 실제 작업을 해봐요">

먼저 검색할 내용을 만들어둡니다.

```
> src/main.py에 TODO 주석을 3개 추가하고,
> src/models.py에 Todo 클래스를 작성하고 TODO 주석을 2개 추가해줘
```

이제 검색 기능을 테스트해보세요.

```
> 프로젝트 전체에서 TODO가 포함된 파일을 찾아줘
```

Claude가 `search_files` 도구로 TODO가 포함된 모든 파일과 해당 줄을 찾아줄 거예요. 더 복잡한 요청도 해보세요.

```
> src 폴더에서 함수 정의를 모두 찾아서, 각 함수의 이름과 파라미터를 정리해줘
```

이번에는 Claude가 여러 도구를 조합해요. `list_directory`로 파일을 확인하고, 각 파일을 `read_file`로 읽은 뒤, 함수 정의를 추출해서 정리해요.

</Step>

<TryIt>

아래 요청들을 순서대로 하면서 Claude가 어떤 도구를 사용하는지 관찰해보세요.

1. "README.md의 내용을 읽어줘" → `read_file`
2. "tests 폴더에 어떤 파일이 있어?" → `list_directory`
3. ".py 확장자 파일을 모두 찾아줘" → `search_files`
4. "main.py의 파일 크기와 마지막 수정 시간을 알려줘" → `get_file_info`

Claude가 도구를 선택할 때 어떤 파라미터를 넘기는지 주의 깊게 살펴보세요. 이것이 <Term id="T-TOOLUSE" />의 작동 원리를 이해하는 핵심이에요.

</TryIt>

### MCP 도구 호출 과정 이해하기

| 단계 | 설명 |
|---|---|
| 1. 요청 분석 | 자연어 요청을 분석해서 어떤 도구가 필요한지 판단해요 |
| 2. 도구 선택 | 사용 가능한 MCP 도구 중 적합한 것을 선택해요 |
| 3. 파라미터 구성 | 도구에 넘길 파라미터를 JSON으로 구성해요 |
| 4. 도구 실행 | MCP 서버에 요청을 보내고 결과를 받아요 |
| 5. 결과 해석 | 반환값을 자연어로 정리해서 사용자에게 보여줘요 |

이 과정이 자동으로 일어나기 때문에 사용자는 그냥 "찾아줘"라고 말하면 돼요. 하지만 과정을 이해하고 있으면 **더 정확한 요청**을 할 수 있어요.

## 4. MCP 서버 관리

<Step n={4} title="등록된 서버를 확인하고 관리해요">

Claude Code를 종료한 상태에서 실행하세요.

```bash
claude mcp list
```

| 명령어 | 기능 |
|---|---|
| `claude mcp list` | 등록된 MCP 서버 목록 조회 |
| `claude mcp add <이름> ...` | 새 MCP 서버 추가 |
| `claude mcp remove <이름>` | MCP 서버 제거 |

</Step>

<TryIt>

메모리 MCP 서버를 추가하면 Claude가 대화 간에 정보를 기억할 수 있어요 — <Term id="T-AGMEM" />의 가장 단순한 형태예요.

```bash
claude mcp add memory -s user -- npx -y @modelcontextprotocol/server-memory
```

추가 후 `claude mcp list`로 두 서버가 등록되었는지 확인하고, Claude Code를 실행해 테스트해보세요.

```
> 내 이름은 김지은이고, 파이썬을 주로 사용해. 이걸 기억해줘
```

새 세션에서 다시 시작하고 물어보세요.

```
> 내 이름이 뭐였지?
```

</TryIt>

### MCP 생태계

| 서버 | 기능 | 제공 |
|---|---|---|
| `filesystem` | 파일 읽기/쓰기/검색 | 공식 |
| `memory` | 영구 기억 저장 | 공식 |
| `brave-search` | 웹 검색 | 공식 |
| `github` | GitHub 이슈/PR 관리 | 공식 |
| `postgres` | PostgreSQL DB 쿼리 | 공식 |
| `slack` | Slack 메시지 읽기/쓰기 | 커뮤니티 |
| `notion` | Notion 페이지 관리 | 커뮤니티 |

MCP 서버 목록은 [modelcontextprotocol/servers](https://github.com/modelcontextprotocol/servers)에서 확인할 수 있어요. **MCP의 강력함은 "표준"에 있어요.** 누구나 서버를 만들 수 있고, 같은 방식으로 Claude에 연결할 수 있어요.

## 5. MCP 보안 고려사항

<Callout type="warn">
MCP 서버에 부여한 권한은 Claude가 자유롭게 사용할 수 있어요. **최소 권한 원칙**을 지키세요.
</Callout>

| 주의 사항 | 설명 |
|---|---|
| **경로 제한** | 파일시스템 MCP에 `~`(홈 전체)를 주지 마세요. 필요한 폴더만 지정 |
| **신뢰할 수 있는 서버만** | 커뮤니티 MCP 서버는 소스 코드를 확인한 후 사용 |
| **민감한 데이터** | API 키, 비밀번호가 있는 폴더를 MCP에 노출하지 마세요 |
| **쓰기 권한** | 읽기만 필요한 경우 쓰기 권한을 제한하세요 |

MCP 서버가 외부에서 내용을 가져오는 경우 <Term id="T-PI" />의 통로가 될 수 있다는 점도 기억하세요.

## 6. 트러블슈팅

<Troubleshoot q="claude mcp add 실행 시 에러가 나요.">
Node.js 버전이 18 이상인지 `node --version`으로 확인하세요. 또한 npx가 설치되어 있는지 `npx --version`으로 확인하세요.
</Troubleshoot>

<Troubleshoot q="MCP 서버가 연결되었는데 도구를 사용하지 못해요.">
Claude Code를 완전히 종료하고 다시 시작해보세요. MCP 설정 변경은 재시작 후 적용되는 경우가 있어요. `/mcp` 명령어로 현재 연결 상태를 확인할 수도 있어요.
</Troubleshoot>

<Troubleshoot q="파일시스템 MCP에서 permission denied 에러가 나요.">
지정한 경로에 읽기 권한이 있는지 확인하세요. 심볼릭 링크나 네트워크 드라이브는 추가 설정이 필요할 수 있어요.
</Troubleshoot>

<Troubleshoot q="MCP 서버가 너무 많아서 Claude가 혼란스러워하는 것 같아요.">
사용하지 않는 서버는 `claude mcp remove <이름>`으로 제거하세요. 도구가 너무 많으면 적절한 도구를 선택하는 데 방해가 될 수 있어요 — <LessonLink id="TH-05" />에서 다룬 MCP의 토큰 부담 문제예요.
</Troubleshoot>

<Troubleshoot q="settings.json을 직접 편집해도 되나요?">
네, JSON 형식만 올바르면 돼요. 다만 문법 오류(쉼표 누락, 따옴표 불일치)가 있으면 Claude Code가 시작되지 않을 수 있으니 주의하세요.
</Troubleshoot>

<Callout type="key">
1. MCP는 AI가 외부 도구와 통신하는 **표준 프로토콜**
2. `claude mcp add`로 서버를 등록하고 settings.json에 저장돼요
3. 파일시스템 MCP로 Claude가 파일을 읽고·검색하고·관리할 수 있어요
4. **user(전역) 또는 project(프로젝트별)** 범위로 설정 가능
5. 보안을 위해 **최소 권한 원칙**을 지키세요
</Callout>
